# GUI Calculator

A responsive calculator built using a single HTML file with HTML, CSS, and JavaScript.

## Features
- Basic operations: Addition, Subtraction, Multiplication, Division
- Clear `C` buttons
- Blue and Red theme UI
- Responsive design - works on mobile and desktop
- Keyboard support

## Technologies Used
- HTML5
- CSS3
- JavaScript
